# ⚡ SmartDNS & UDP Hub

Легковесный SmartDNS-сервер на базе `dnsmasq` и `sniproxy` с веб-панелью управления, пробросом UDP-портов (`iptables NAT`) и системой персональных DDNS-токенов для автоматического обновления IP клиентов.

Подходит для развертывания на VPS (Ubuntu 22.04 / 24.04, включая минимальные тарифы уровня `e2-micro`).

## Возможности
- **Точечное проксирование или Wildcard-режим:** перенаправление только выбранных сервисов (Xbox, Microsoft Rewards, Gemini, ChatGPT, Claude, Discord и др.) без снижения скорости загрузки игр и прямого мультиплеера.
- **Веб-панель управления (порт 8080):** управление доменами, готовые пресеты в 1 клик, живой лог DNS-запросов с фильтром и встроенная проверка работы доменов.
- **Белый список IP + персональные DDNS-вебхуки:** защита сервера от посторонних через `iptables` и выдача индивидуальных ссылок пользователям для автообновления их динамического IP.
- **UDP NAT-проброс:** перенаправление выбранных UDP-портов на целевые серверы.
- **Оптимизация из коробки:** автоматическое отключение `systemd-resolved`, блокировка утечек IPv6 (`filter-AAAA`), создание Swap 1 ГБ и снятие лимитов открытых соединений (`LimitNOFILE=65535`).

## Требования к брандмауэру (Firewall)
Перед установкой откройте в панели управления вашего облачного провайдера (GCP, AWS и др.) следующие входящие порты для `0.0.0.0/0` (фильтрацию по IP возьмет на себя сама панель):
- **TCP:** `53, 80, 443, 8080`
- **UDP:** `53` *(плюс нужные игровые порты, если используете UDP NAT)*

## Быстрая установка (Ubuntu 22.04 / 24.04)

Подключитесь к серверу по SSH и выполните одну команду:

```bash
curl -sL [https://raw.githubusercontent.com/XP9Cb/smartdns-udp-hub/main/install_panel.sh](https://raw.githubusercontent.com/XP9Cb/smartdns-udp-hub/main/install_panel.sh) -o install_panel.sh && sudo bash install_panel.sh
```

Во время установки скрипт предложит задать пароль для входа в веб-панель (если просто нажать `Enter`, установится `dns2026`).

После завершения панель будет доступна по адресу:
`http://IP_ВАШЕГО_СЕРВЕРА:8080`

## Настройка клиентов
- **Xbox:** в сетевых настройках консоли укажите IP вашего VPS в качестве основного DNS, а дополнительный оставьте `0.0.0.0`.
