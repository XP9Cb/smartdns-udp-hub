# ⚡ SmartDNS & UDP Hub

Легковесный SmartDNS-сервер на базе `dnsmasq` и `sniproxy` с веб-панелью управления, пробросом UDP-портов (`iptables NAT`) и системой персональных DDNS-токенов для автоматического обновления IP клиентов.

Подходит для развертывания на VPS (Ubuntu 22.04 / 24.04, включая минимальные тарифы уровня Google Cloud `e2-micro` и Amazon AWS EC2).

## Возможности
- **Точечное проксирование или Wildcard-режим:** перенаправление только выбранных сервисов (Xbox, Microsoft Rewards, Gemini, ChatGPT, Claude, Discord, Spotify и др.) без снижения скорости загрузки игр и прямого мультиплеера.
- **Веб-панель управления (порт 8080):** управление доменами, готовые пресеты в 1 клик, встроенная проверка работы доменов, ручной перезапуск служб и экспорт/импорт настроек в JSON.
- **Наглядный цветной Live Log:** отображает имя клиента, IP-адрес, запрашиваемый домен и итоговый маршрут (`🟢 ЧЕРЕЗ ПРОКСИ` или `🔵 НАПРЯМУЮ`) с локальным временем браузера, выбором глубины журнала и мгновенным поиском.
- **Белый список IP + персональные DDNS-токены:** защита сервера от посторонних через `iptables` и выдача индивидуальных ссылок пользователям для автообновления их динамического IP.
- **UDP NAT-проброс:** перенаправление выбранных UDP-портов на целевые серверы.
- **Оптимизация из коробки:** автоматическое отключение `systemd-resolved`, блокировка утечек IPv6 (`filter-AAAA`), создание Swap 1 ГБ и снятие лимитов открытых соединений (`LimitNOFILE=65535`).

## Требования к брандмауэру (Firewall)
Перед установкой откройте в панели управления вашего облачного провайдера (GCP, AWS Security Group и др.) следующие входящие порты для `0.0.0.0/0` (фильтрацию по IP возьмет на себя сама панель):
- **TCP:** `53, 80, 443, 8080`
- **UDP:** `53` *(плюс нужные игровые порты, если используете UDP NAT)*

## Быстрая установка (Ubuntu 22.04 / 24.04)

Подключитесь к новому серверу по SSH и выполните одну команду:

```bash
curl -fsSL https://raw.githubusercontent.com/XP9Cb/smartdns-udp-hub/main/install_panel.sh | tr -d '\r' > install_panel.sh && sudo bash install_panel.sh
```

Во время установки скрипт предложит задать пароль для входа в веб-панель (если просто нажать `Enter`, установится `dns2026`).

После завершения панель будет доступна по адресу:
`http://IP_ВАШЕГО_СЕРВЕРА:8080`

## Обновление уже работающего сервера

Чтобы обновить веб-панель и системные службы до последней версии с сохранением пароля, белого списка IP, доменов и DDNS-токенов, выполните на сервере:

```bash
curl -fsSL https://raw.githubusercontent.com/XP9Cb/smartdns-udp-hub/main/update.sh | tr -d '\r' | sudo bash
```

## Настройка клиентов
- **Активация доступа:** создайте в панели персональный DDNS-токен с именем пользователя/устройства и откройте полученную ссылку в браузере на нужном устройстве — сервер автоматически добавит его IP в белый список.
- **Xbox:** в сетевых настройках консоли укажите IP вашего VPS в качестве основного DNS, а дополнительный оставьте `0.0.0.0`.
- **Windows:** укажите IP вашего VPS в свойствах IPv4 сетевого адаптера и отключите IPv6.
